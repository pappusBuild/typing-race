# Typing Game Web

## Deskripsi
Typing Game adalah aplikasi web untuk melatih kemampuan mengetik 10 jari sekaligus meningkatkan kemampuan bahasa Inggris. Pengguna dapat bermain, melihat statistik WPM dan Accuracy, serta bersaing melalui leaderboard.

## Fitur
- Login & Register
- Mode latihan
- Mode challenge
- WPM Calculator
- Accuracy Calculator
- Leaderboard
- Profile User
- Riwayat permainan
- Admin Dashboard
- Soal/Quote Management
