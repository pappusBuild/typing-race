# Software Requirements Specification

## Functional Requirements

### Authentication
- User dapat register
- User dapat login
- User dapat logout

### Gameplay
- User memilih mode permainan
- Sistem menampilkan kata
- Sistem menghitung WPM
- Sistem menghitung Accuracy
- Sistem menyimpan skor

### Leaderboard
- Menampilkan ranking
- Filter harian
- Filter mingguan
- Filter all time

### Profile
- Edit profil
- Riwayat permainan
- Statistik bermain

### Admin
- CRUD Quotes
- CRUD User
- Melihat statistik

---

## Non Functional Requirements

Performance
- Response < 2 detik

Security
- Password di-hash
- JWT Session

Usability
- Responsive
- Mudah digunakan

Compatibility
- Chrome
- Edge
- Firefox
